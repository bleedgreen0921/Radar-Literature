# 基于RAD张量的雷达目标探测

------

## A recurrent CNN for online object detection on raw radar frames

### 概述

本文提出了一种名为**RECORD（Recurrent CNN for Online Radar Object Detection）**的新型架构，用于在原始雷达数据帧上进行在线目标检测。RECORD是一种基于循环卷积神经网络（CNN）的方法，结合了2D卷积和卷积长短期记忆网络（ConvLSTMs），以学习雷达数据的**时空依赖性**。该模型是因果的（仅依赖过去信息），适用于实时高级驾驶辅助系统（ADAS）应用。

此外，本文使用高效的卷积和卷积神经网络（反向残差块和瓶颈LSTM）来降低计算成本。提出的模型是端到端可训练的，不需要预训练或多个训练步骤。同时提出了一种通用方法，可以处理RA、RD或RAD光谱，并在不同任务上优于最先进的架构。

### 问题建模

让我们考虑从时间k−N+1到k的N个雷达帧的序列R，例如：`R={rk−N+1，…，rk}`。

我们的目标是基于过去的N帧，在时间k，pk找到场景中每个对象的位置。我们用两个函数定义我们的模型，编码器E和解码器D。

我们考虑一个因果模型，这意味着它只使用过去来预测下一个时间步。对于序列的每个时间步长k，我们考虑一个循环卷积编码器，将时间 `k` 的帧和一组 `I` 个先前隐藏状态 `Hk-1={h^0_{k−1}，…，h^i_{k−1}，…，h^{I-1}_{k−1}}` 作为输入，如果使用多个循环单元，则 `i` 是循环单元的索引。

编码器返回一组特征映射 `Fk` 和一组更新的隐藏状态 `H_k={h0k，…，hik，…，hi-1k}` ，使得：`E（r_k，H_{k-1}）=（Fk，Hk）`。

由于我们的编码器对过去的N帧进行循环编码，以预测时间步长k处对象的位置，因此我们的解码器是一个全卷积解码器，它将编码器更新的隐藏状态Hk（存储器）和特征图Fk（时空特征图）集作为输入，使得：D（Fk，Hk）=pk。

## Cross-Modal Supervision-Based Multitask Learning With Automotive Radar Raw Data

### 研究背景与问题：

​	随着机器学习的蓬勃发展，更具体地说是深度学习（DL），基于摄像头或基于激光雷达的驾驶系统取得了巨大的发展，但它们对天气和光照条件很敏感。此外，对于这些系统来说，通过一次测量来区分运动和静止物体是极具挑战性的。相比之下，基于雷达的方法在这些场景下是更有利的，因为它能够在恶劣的环境条件下稳健地工作，同时测量物体的精确相对径向速度。然而，考虑到其角分辨率，普通雷达传感器无法与其他两种模态传感器相提并论。具体来说，目前的汽车级雷达通常可以在约1◦  ，这比激光雷达或相机差得多。此外，雷达数据噪音更大，有许多鬼目标。因此，雷达在整个感知系统中通常具有较低的置信度，以避免频繁的误报问题。

​	此外，雷达传感器没有统一的数据格式。它可以是模数转换器（ADC）信号、距离方位多普勒张量（或称为RAD雷达立方体）或点云数据。此外，与相机或激光雷达相比，包含雷达测量的公共数据集的发布仍然有限。雷达立方体数据的可用性甚至更难，由于其丰富的信息，人们认为它在感知任务中具有巨大的潜力。所有这些原因都阻碍了基于雷达的感知系统的发展。

​	对于监督学习，访问标记数据是先决条件。通常，雷达点云采用手动标记，这既费时又劳动密集。然而，当涉及到雷达RAD数据时，手动标记是相当具有挑战性的，甚至是不可行的，因为这些数据对人类来说并不容易理解。

------

### 主要贡献：

​	为了解决雷达数据的标记问题，本文关注与雷达测量**时间同步、空间重叠**的相机图像。本文采用了创新的**跨模态训练**方法，并将其标签范围从单一自由空间（语义层面）扩展到自由空间和道路使用者（全景层面）。更具体地说是从相机图像生成全景分割掩模，它意味着我们的模型真实基准和最终输出是相机视角，而不是雷达的鸟瞰图BEV视角。

​	通过这种训练方法，我们可以使用雷达距离-多普勒RA矩阵来解决基础设施分类任务以及更具挑战性的移动道路用户检测。分割的摄像机图像可以由现成的全景分割网络自动生成，为雷达数据的训练提供**监督信号**。由于从地面实况准备到训练深度神经网络（DNN）的所有步骤都可以自动实现，因此我们提出了一种摄像机雷达系统概念，可以自动利用雷达数据通过摄像机的监督信号来训练DNN。
根据我们的努力，我们发现将道路使用者视为自由空间并不是一个明智的选择。因此，我们调整分割后的图像来实现雷达定制的全景分割，可以分解为自由空间分割和目标检测任务。

1. 将基于相机图像的训练方法扩展和调整到道路使用者。因此，实现了相机图像中的雷达定制全景分割。
2. 基于这种训练方法，提出了一种摄像机雷达系统概念，可以自动利用分割的图像数据作为监督信号，用雷达数据训练DNN。
3. 设计和分析了新颖的纯雷达模型，该模型解决了自由空间分割和对象检测问题，并且它的性能优于之前作品。

### 数据预处理

​	为了生成分割图像，我们首先从Detectron 2 库中获取预训练的全景特征金字塔网络（FPN），然后使用Cityscapes数据集对其进行微调。考虑到Radial数据集中的测量场景，Cityscapes中的所有标签都简化为物体类别中的车辆、场景结构类别中的道路和非道路。在这里，我们称它们为车辆、自由空间和非自由空间。对于车辆类别，实现了语义标签、边界框和实例ID的实例级注释，而自由空间和非自由空间仅具有语义标签。除了分割标签外，还准备了三个热图，即关键点预测、偏差和深度热图，用于对象检测。

### 提出方法：

#### Cross-Modal Supervision 跨模态监督

要应用基于监督学习的DL算法，必须提前准备标记数据。手动标记是相机图像等数据常用的方法;然而，它会消耗大量的时间和劳动力。对于雷达数据，标记比相机图像更具挑战性，因为雷达数据的噪音要大得多。这些都影响了标记的负担和质量。

此外，代表距离、多普勒和角度（方位角甚至高度）维度的物体的雷达立方体数据对于人类来说并不简单可以理解。考虑到对象的这种表示方式和雷达立方体数据的复杂性，关于雷达立方体中的标记仍然没有达成共识。

考虑到这些问题，提出了一种完全自动的注释方法，该方法完全不受雷达的幽灵目标问题的影响，不仅可以在实例级别注释对象，还可以在语义级别注释内容。

![image-20250627171832695](C:\Users\adminqiu\AppData\Roaming\Typora\typora-user-images\image-20250627171832695.png)

**先决条件**：注释的输入应为**时间同步**且在空间上与雷达具有**共同检测区域**的相机的图像。

1. **输入数据同步处理**
   - **雷达端**：原始雷达信号 → 生成 **距离-多普勒矩阵**（核心输入）
   - **相机端**：原始图像 → **畸变校正** → **全景分割网络**生成语义标签
   - **时空对齐**：通过 **时间同步 & 空间重叠** 确保数据严格匹配
2. **跨模态监督机制**
   - 相机生成的 **全景分割结果（Pseudo-Label）** 伪标签直接作为监督信号
   - **无需人工标注**：伪标签驱动 **Radar DNN** 端到端训练
3. **双阶段应用逻辑**
   - **训练阶段**：相机提供监督信号 → 优化雷达模型
   - **推理阶段**：训练完成的 **Radar DNN** 可独立输出感知结果（雷达自主推理）

#### Camera-Radar System Concept 相机-雷达系统概念

![image-20250627183434870](C:\Users\adminqiu\AppData\Roaming\Typora\typora-user-images\image-20250627183434870.png)

相机-雷达系统可以在相机监督信号下利用雷达数据实现自动DNN训练，并在图像平面上实现自适应摄像机-雷达融合。为了确保系统正常工作，必须满足两个传感器应该在空间上具有共同的视野（FoV）并且应该保持良好的时间同步。

1. **第一阶段**

   第一阶段基本上是图2（a）中描绘的训练阶段。在此阶段，摄像机系统为雷达训练提供地面实况。该系统采用全景分割算法，分割后的图像被用作利用雷达数据进行DNN训练的地面实况。在这个阶段，相机的预测结果比雷达的预测结果可靠得多，因此，该阶段我们主要信任相机。用足够的数据训练雷达，并且其预测结果与相机相当后进入第二阶段。

2. **第二阶段**

   第二阶段，即（b）和（c），此时系统将根据给定情况决定仅信任一个或两个传感器。在这个阶段，系统实际上处于融合工作模式。对于（b），在适合相机的工作条件下，考虑相机和雷达的结果。 相比之下，对于（c），在雾、雨或雪等恶劣天气条件下，或者当摄像机工作异常时，系统更信任雷达而不是摄像机。

#### Semantic Segmentation With Radar Range-Doppler Matrix 基于雷达距离-多普勒矩阵的语义分割

![image-20250627190049351](C:\Users\adminqiu\AppData\Roaming\Typora\typora-user-images\image-20250627190049351.png)

图3我们可以观察到两种现象。首先，由于分割基本正确，DNN能够通过Range-Doppler矩阵了解环境。其次，不同类别之间的分割结果差异显著。 对于自由空间和非自由空间，分割相当精确，而对于车辆来说则相对较差。造成这种差异的原因显而易见，即使是高清雷达，其角度FoV和分辨率也无法与普通相机系统相提并论，而且性能差距巨大。因此，用雷达数据训练的模型无法精确分割相机图像中的小物体。

因此，我们提出了一种新的适应应用于道路用户，以实现雷达量身定制的全景分割。我们的灵感来自于[15]中的核心思想，即在对象检测过程中将对象建模为**关键点**（其**边界框的中心点**）。不像其他检测器，如Faster RCNN [26]，YOLOv 3 [16]通过轴对齐，紧密包围的边界框表示对象，[15]通过边界框中心的单个点表示对象。物体检测分为**关键点的估计**和**从关键点的特征回归其他属性**，如大小，方向，3D位置，甚至姿态。

在我们的工作中，DNN被训练来预测相机图像平面中的**物体中心位置和深度**。由于移动物体由单点表示，因此我们绕过了对物体精确形状和大小的估计，这超出了雷达的感知能力。与相机相比，雷达有一个本质优势：可以准确检测到物体的距离。考虑到这一点，作为额外特征的移动对象的距离（即图像平面的深度）也从该DNN回归。除了检测移动物体外，DNN还同时将周围环境分类和分割为图像平面中的两类，即自由空间和非自由空间。通过结合来自环境的语义层信息和来自对象的实例层信息，DNN实现了雷达定制的全景分割。

#### DNN Structure

![image-20250627191127336](C:\Users\adminqiu\AppData\Roaming\Typora\typora-user-images\image-20250627191127336.png)

DNN的结构如图4所示。基本上，采用**U-Net结构**，可分为三个部分：编码器和解码器中的检测和分割分支。

距离多普勒矩阵最初由16个接收器组成的16个通道的复数组成，我们将复数分为实部和虚部，形成大小为256×512×32的输入数据。

在编码器部分，我们使用**扩展卷积 (Dilated Conv)**来对具有更大接收域的输入进行编码，具体来说，扩张卷积核大小为12×1，扩张率为16×1。**Conv.Block** 中的两个卷积层具有3×3的核大小。对于输入距离多普勒矩阵，角度信息在信道维度中编码。因此，卷积块中包含了沿信道维度的自关注层[27]，以增强跨信道相关性。编码器的输出包括从距离多普勒矩阵中提取的特征，并将其传递给解码器中的检测和分割分支。在检测分支中，输出是图4所示的关键点预测、偏移和深度热图。由于关键点热图比原始输入大小小四倍，因此需要一个偏移热图来估计关键点在行和列方向上与原始大小图像之间的位置偏移。此外，深度热图负责估计图像平面的关键点深度。除了检测分支之外，解码器还有一个分割分支，用于预测图像平面中的自由空间。
