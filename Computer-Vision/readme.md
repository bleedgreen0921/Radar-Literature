以下是计算机视觉领域必学的深度学习模型，涵盖经典方法与前沿进展，结合其核心思想、应用场景及最新演进：

------

### **一、基础骨干网络**

1. **卷积神经网络（CNN）**
   - **核心思想**：通过卷积层提取局部特征（边缘、纹理），池化层压缩空间维度，全连接层实现分类/回归。
   - 经典模型：
     - **AlexNet**：首个深度CNN，引入ReLU和Dropout，2012年ImageNet夺冠。
     - **VGGNet**：深层堆叠3×3卷积，证明深度提升性能（如VGG16/VGG19）。
     - **ResNet**：残差连接解决梯度消失，支持千层网络训练（如ResNet-50），成为工业标准。
   - **演进**：2025年ResNet仍广泛用于3D重建与医疗影像分析。
2. **轻量化CNN**
   - **MobileNet**：深度可分离卷积减少计算量，适合移动端部署。
   - **EfficientNet**：复合缩放（深度/宽度/分辨率）平衡效率与精度，2023年后成为主流。

------

### **二、特定任务模型**

#### **目标检测**

1. **两阶段模型**

   - **R-CNN (2014)**: 使用候选区域（region proposals）和CNN结合，显著提高了目标检测性能。
   - **Fast R-CNN (2015)**: 提出了ROI池化层（ROI Pooling），提高了速度和性能。

   - **Faster R-CNN**：区域提议网络（RPN）生成候选框，分类网络精调位置与类别，精度高但速度慢。
   - **Mask R-CNN**：扩展Faster R-CNN，增加掩码分支实现实例分割（如细胞分割）。

2. **单阶段模型**

   - **YOLO系列**：单次检测实现端到端预测，2025年YOLOv10支持长视频实时分析（>100 FPS）。
   - **SSD**：多尺度特征图检测不同尺寸物体，平衡速度与精度。

#### **语义分割**

- **U-Net**：对称编码器-解码器结构，跳跃连接保留细节，主导医疗影像分割（如肿瘤识别）。
- **DeepLab系列**：空洞卷积扩大感受野，多尺度融合提升边界精度（如DeepLabv3+）。
- **SegMAN（2025）**：结合局部注意力与动态状态空间模型，解决长距离依赖问题。

#### **图像生成与风格迁移**

- GAN：生成器与判别器对抗训练，生成逼真图像。
  - **CycleGAN**：无配对图像转换（如马→斑马）。
  - **StyleGAN**：风格向量控制生成细节，支持高分辨率人脸合成。
- **扩散模型（2025前沿）**：文本驱动风格迁移，实现可控艺术化生成。

------

### **三、序列与跨模态模型**

1. **循环神经网络（RNN）**
   - **LSTM/GRU**：处理时序数据，用于视频动作识别（如跌倒检测）。
2. **Transformer**
   - **ViT（Vision Transformer）**：将图像分块输入Transformer，全局建模能力强，2024年后主导大规模分类任务。
   - **Swin Transformer (2021)**: 基于窗口化的Transformer设计，能够有效捕捉局部和全局信息，逐步替代了CNN在视觉任务中的主导地位。
   - **DETR (Detection Transformer, 2020)**: 通过Transformer架构进行目标检测，去除了传统的候选区域生成，开创了目标检测的新方向。
   - 多模态模型：
     - **CLIP**：联合训练图像-文本对，支持零样本识别（OpenAI）。
     - **BLIP-2**：融合视觉与语言，用于视觉问答（VQA）。

------

### **四、前沿研究方向（2025）**

1. **自监督学习**
   - **SimCLR/MoCo**：利用无标签数据预训练，减少标注依赖。
2. **高效模型设计**
   - **MambaVision**：结合状态空间模型（SSM）与Transformer，降低计算复杂度（Nvidia CVPR 2025）。
3. **3D视觉重建**
   - **NeRF**：神经辐射场生成逼真3D场景，应用于元宇宙建模。
4. **可解释性AI**
   - 可视化特征重要性，提升医疗诊断可信度。
